이벤트 안내
* 이벤트명: 인천어린이천문대 2026 금성 목성 근접 관측 글짓기이벤트
* 참가 대상: 정규대원
* 행성 촬영 기간: 6월 6일 ~ 11일
* 금성과 목성이 가장 근접해 보이는 기간입니다.
* 글짓기 제출 기한: 6월 30일까지

참여 방법
1. 목성과 금성의 근접 현상을 관측 및 촬영하고 느낀 점과 소감을 작성합니다.
2. 작성 후 저장하기를 눌러 이미지를 저장합니다.
3. 인스타그램에 이미지를 올려주세요! 인천어린이천문대 태그(@astrocamp_incheon) 및 4가지 필수 해시태그를 포함해주세요!
* #금성
* #목성
* #인천어린이천문대
* #2026금성목성

4. 업로드 후 천문대 DM으로 학생 정보(반, 이름)를 보내주세요!
5. 참여하신 모든 분에게 상품을 드립니다!
* 상품: 천문대 굿즈
* 장마철 필수템 우산 + 스트링백

저장 안내
1. 카카오톡 브라우저에서는 브라우저 정책상 자동 저장이 제한될 수 있습니다. 카카오톡에서  저장 화면이 뜨면 이미지를 꾹 눌러 저장해 주세요.
2. 크롬, 삼성 브라우저, 사파리에서는 저장하기 버튼으로 PNG 저장이 가능합니다.
3. 이미지를 만드는 데 시간이 조금 걸릴 수 있으니 저장 중에는 잠시 기다려 주세요.
