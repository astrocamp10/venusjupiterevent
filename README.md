금성 목성 근접 글쓰기 이벤트 홈페이지.

홈페이지 사용 방법.

1. 관측 날짜, 관측시간, 관측 장소, 관찰 메모 질문 3개 => 각각 개인 텍스트 칸이 있어 개별 답변 작성 가능
2. 이미지 추가 칸을 클릭 [ 휴대폰에서는 터치 ] 하면 사진 첨부가 가능하며 기본 초기 사진은 칸에 꽉 차게끔 설정.
3. 사진 첨부 후 옆에 슬라이더로 사진 크기를 확대 및 축소할 수 있으며 확대 시 마우스 및 터치로 사진 위치 조정 가능
4. 저장하기 버튼을 누르면 기본적으로 형식에 맞게 작성한 글 및 이미지를 포함 모두 png 파일로 저장됨. 크롬 및 삼성 브라우저 사파리에서는 잘 작동 됨.
5. 카카오톡 브라우저에는 보여지고 있는 화면을 저장할 수 없는 정책을 운영하고 있어서 이미지를 눌러 저장하는 방법이 유일한 방법. 카카오톡 브라우저는 자동으로 인식해 안내 팝업이 뜨게 만들어짐. [ 카카오톡 브라우저 정책상 꾹 눌러 이미지 저장하기를 해주세요 ]
